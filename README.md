# 染整实验台 · 打样与样品交接管理

把每次打样和后续处置串到一张打样单上，全流程状态机管理：

1. **新建打样单**：录入客户订单、布种、目标色号、目标 Lab（可选，用于 ΔE 对比）和染料配方（目标重量）。
2. **配料称量**：逐项录入实称重量；偏差超过 ±0.01g 自动留痕（偏差日志），且存在超差项时**阻止完成配料**，须重新称量至允差内。
3. **打样后质控**：录入 Lab 三轴读数与保温记录（温度/时长，可多段），提交后结果进入**待确认**。
4. **负责人确认**：确认前样品交接入口锁定，**不能把样品交给客户**；确认后放行。
5. **样品交接**：领取（登记领取人/经办人）或退库（必填退回原因）均关联原打样单；退库自动生成**待重打记录**，可一键按原配方生成重打单。
6. **列表查看交接**：打样单列表支持按色号、客户订单、状态筛选，并展示每单最近交接记录。

数据保存在浏览器 localStorage，可点右上角「重置演示数据」恢复初始样例。
