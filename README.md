# hxyfront-62012 纺织染整打样流转与样品交接管理

染整实验台打样单全流程管理前端：把每次打样与后续处置（称量、质控、确认、交接、重打）串起来。

## 功能流程

1. **新建打样单**：录入客户订单号、布种、目标色号、目标 Lab（选填）、浴比与配方明细。
2. **配料称量**：配方逐项称量，偏差超过 ±0.01g 自动标红留痕（历史记录保留），存在超差或未称项时阻止「完成配料」。
3. **打样**：配料完成后上机打样，打完送质控。
4. **质控**：录入 Lab 三轴读数（自动算 ΔE*76）与保温记录（温度 × 时长，可多段），提交后进入待确认。
5. **负责人确认**：确认前领取 / 退库按钮均锁定，样品不能交给客户。
6. **样品交接**：领取、退库都关联原打样单；退库必填原因并自动生成「待重打」记录，可一键生成关联原单的重打单。
7. **台账列表**：按色号、客户订单、状态筛选，直接查看每单最近交接情况。

数据保存在浏览器 localStorage，内置 5 张不同状态的演示打样单。
